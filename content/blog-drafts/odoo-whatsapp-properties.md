## Why Your Odoo Is Always Out of Date

**To update Odoo from WhatsApp means letting an AI layer read your WhatsApp conversations and write the results — new contacts, fresh leads, and summary notes — straight onto the matching Odoo records, so nobody has to retype the chat.**

The reason Odoo goes stale isn't laziness. It's physics. A rep runs thirty live threads a day. Each one produces a fact worth logging — a phone number, a budget, a decision date, a complaint. Multiply that across a team and "just update the CRM" becomes an hour of copy-paste nobody has time for.

So the update either happens late, happens wrong, or doesn't happen at all. The CRM you're supposed to trust as a single source of truth becomes a rough approximation of what your reps *remember*.

Automatic updates flip that. Instead of asking the human to feed the CRM, you let the conversation feed it.

## WhatsApp Is a Black Box (And Reps Won't Update the CRM)

Two things are true at once, and together they're the whole problem.

**One: WhatsApp is invisible to the business.** The deal is being negotiated in a thread on someone's phone. You can't search it, report on it, or forecast from it. If that rep goes on leave — or leaves entirely — the account history walks out with them.

**Two: reps hate CRM data entry, and no pep talk fixes that.** Logging a call feels like admin, not selling. Every field you add to the "please fill this in" list makes it less likely anything gets filled in. This is not a discipline issue you can train away; it's an incentive mismatch.

The usual fix — nagging people to update Odoo — fails for the same reason it always has. The durable fix is to remove the human from the logging loop entirely: read the chat, write the record. That's the layer Eazybe adds.

## Not Just Contacts: Leads and Notes on the Record

"Update the CRM" shouldn't mean "save a phone number." A conversation contains a lead, not just a name — so Eazybe's Mini-CRM for Odoo works across more than the contact card:

- **Contacts — create and edit:** name, email, phone, company, and other fields, so the person record stays complete and correct.
- **Leads — create:** lead title, contact person, expected revenue, probability, and expected closing date, so a promising thread becomes a trackable opportunity instead of a lost DM.

## How the Updates Sync (Setup in a Few Steps)

Connecting Eazybe to Odoo is a one-time setup, then it runs quietly in the background.

1. **Have an active Odoo account** with administrator or user access.
2. **Copy your Odoo Instance URL** — include `https://` and no trailing slash.
3. **Generate an API key in Odoo** at *Settings → Users → Security → API Keys*. The user needs API-access permission for this.
4. **Connect Eazybe** by pasting the Instance URL and the API key.
5. **Label the chats you want synced.** Chat backup is **label-based** — only contacts carrying the WhatsApp labels you select are backed up — so you stay in control of what flows into Odoo.
6. **Open the Mini-CRM panel, set your properties (Edit Properties), and go.** Records sync to your Odoo instance, viewable any time via the **"View on Odoo"** button.

No Odoo seat for everyone on the team? Eazybe can also back your labeled chats up to a **Google Sheet** as a lightweight home — a simple option, though a Sheet won't hold Odoo's lead objects the way Odoo does.

## FAQs Related To Updating Odoo From WhatsApp

**1. How do I update Odoo from WhatsApp automatically?**
Connect Eazybe to your Odoo instance with your Instance URL and an API key, label the WhatsApp chats you want synced, and choose your properties in the Mini-CRM panel. From then on, Eazybe reads those conversations and writes Contacts, Leads, and Notes into Odoo for you — no manual logging.

**2. What Odoo objects can Eazybe create or update?**
For Odoo, the Mini-CRM creates and edits **Contacts** (name, email, phone, company, and more), creates **Leads** (lead title, contact person, expected revenue, probability, expected closing date), and creates or adds **Notes** on a contact. It does not create Deals, Tickets, Tasks, Call Logs, or Events.

**3. Do my reps still have to update the CRM by hand?**
No — that's the whole point. Eazybe reads the conversation and writes the record, so the update happens even when a rep is too busy to log anything. You can still review and edit what lands, especially on big accounts.

**4. Can I control which fields get updated?**
Yes. Click the **Edit Properties** button in the Mini-CRM panel, select exactly which Odoo properties should appear and update, and Save. Eazybe then writes only against the fields you chose.

**5. Does the whole WhatsApp transcript get dumped into Odoo?**
No. Eazybe writes a concise **gist** and your selected property values onto the record, so it's scannable. The full chat is backed up separately under the "WhatsApp Chats by Eazybe" menu and against the contact, if you ever need the raw thread.

**6. Is the sync two-way, and how often does it run?**
For Odoo, sync is **one-way** (WhatsApp → Odoo), and the docs don't publish a fixed interval or an initial-backup window — so we won't quote a specific cadence. Chat backup is label-based: only contacts carrying your selected WhatsApp labels sync.

**7. What do I need before I start?**
An active Odoo account with admin or user access, your Odoo Instance URL (with `https://` and no trailing slash), and an API key generated in Odoo under *Settings → Users → Security → API Keys* by a user with API-access permission.
